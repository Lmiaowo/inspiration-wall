# 靈感卡片牆 · Inspiration Card Wall

> 把冒出來的靈感、讀到的好句子、語錄隨手記下來，讓它們像傳送帶一樣在頁面裡自動流動展示。

一個純前端單頁應用，無後端、無構建步驟、無外部依賴。打開 `index.html` 即用，資料存在瀏覽器本地。

---

## 特色

### 三種視圖自由切
- **傳送帶** — 單行橫向（或豎向）自動滾動展示
- **瀑布** — 多行多列同時滾動，相鄰軌道方向相反，營造流動節奏
- **網格** — 靜態瀏覽全部卡片，支援拖曳排序

### 滾動與互動
- 自動勻速滾動，滑鼠懸停某張卡時**徹底暫停**方便閱讀
- 非懸停卡片保留輕微「水中浮動」左右搖晃效果
- 橫向瀑布固定 2 行，一行向左、一行向右
- 竖向瀑布固定 3 列，中間列隨機上下方向，兩邊列與中間相反
- 邊緣柔和漸隱，不裁切卡片陰影與懸停放大

### 配色：莫蘭迪色系
- 內建 6 種低飽和度莫蘭迪漸變預設（薄紗藍 / 霧凇灰 / 薄荷灰 / 淡丁香 / 雲水灰 / 青瓷灰）
- 每次刷新隨機分配全域底色；卡片不足時從未用過的顏色中去重挑選
- 每張卡片也可單獨自定義：漸層（兩色 + 角度）或純色
- 角度池隨機：85° / 100° / 115° / 130° / 145° / 160°（避免千篇一律的 135°）

### 設計語言
- 畫布：暖米色 `#f3ede1`
- 強調：珊瑚紅 `#cc785c`
- 字體：[Shippori Mincho B1](https://fonts.google.com/specimen/Shippori+Mincho+B1)（上世紀東京築地活字 No.5 古典明朝，三角襯線、字身窄長）+ Noto Serif TC + Klee One
- 圓角克制、陰影柔和，整體偏 Anthropic 暖色編輯風

### 其他
- 搜尋框即時過濾標題 / 正文 / 來源 / 標籤，關鍵詞高亮
- 標籤 chip 一鍵篩選
- 新建 / 編輯 / 刪除（自定義 modal 二次確認，不用原生 `confirm()` 避免執行緒阻塞）
- 資料 `localStorage` 本地持久化，支援 JSON 匯入 / 匯出
- 響應式，移動端無橫向滾動
- 全繁體中文介面

## 快速開始

```bash
# 1. Clone
git clone https://github.com/<你的帳號>/inspiration-card-wall.git
cd inspiration-card-wall

# 2. 直接打開
# 任意現代瀏覽器打開 index.html 即可

# 或者用本地伺服器（推薦，避免某些瀏覽器對 file:// 的限制）
python -m http.server 8765
# 然後訪問 http://localhost:8765/
```

> 字體透過 Google Fonts CDN 引入，首次載入需要聯網。

## 功能速覽

| 操作 | 入口 |
|------|------|
| 新建卡片 | 右上角「＋ 新建」按鈕 |
| 編輯卡片 | 點卡片 → 「編輯」 |
| 刪除卡片 | 點卡片 → 「刪除」 → 自定義確認框二次確認 |
| 切換視圖 | 頂欄 🎞️ 傳送帶 / 🌊 瀑布 / 🔲 網格 |
| 切換方向 | 頂欄 ↔ 橫向 / ↕ 豎向 |
| 搜尋 | 頂部搜尋框，即時過濾 + 高亮 |
| 標籤篩選 | 搜尋框下方的 tag chip |
| 單卡配色 | 新建/編輯彈窗內「跟隨全域預設」開關 + 色盤 + 角度滑桿 |
| 設定 | 右上角 ⚙ 按鈕（滾動速度、行數、浮動幅度等） |
| 匯入 / 匯出 | 設定面板內 |

## 資料格式

卡片物件結構（`localStorage` key：`inspiration_cards_v2`）：

```json
{
  "id": "lxp3a-abc12",
  "title": "靈感的標題",
  "body": "正文內容，支援多行",
  "source": "來源出處",
  "tags": ["靈感", "語錄"],
  "bg": null,
  "createdAt": "2026-08-15T12:46:00.000Z"
}
```

- `bg` 為 `null` 時跟隨全域預設，每次刷新從莫蘭迪色卡中隨機分配
- `bg` 為 `{ type: "gradient", c1, c2, angle }` 或 `{ type: "solid", c1 }` 時使用卡片自身配色

## 設計取捨

- **不用原生 `confirm()`** — 會阻塞主執行緒且樣式無法自定義，改用自定義 modal 二次確認
- **無縫滾動複製策略** — 內容不足時自動複製到填滿 2 倍 viewport，保證無縫循環始終有足夠距離
- **隨機配色去重** — 同屏內若多張卡片都跟隨全域，會從未使用過的顏色中挑選，避免同色
- **邊緣漸隱而非硬裁** — 用 `::before / ::after` 偽元素覆蓋 60px 寬漸層，取代 `mask-image`，避免陰影與懸停放大被裁掉
- **強制滾動模式** — 瀑布視圖不再因「內容未填滿」進入靜止 float 狀態，始終保持流動
